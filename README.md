# Triplan — 함께 만드는 여행

[웹 체험판](https://piason10.github.io/Triplan/) · [GitHub 저장소](https://github.com/piason10/Triplan)

React 19 · TypeScript · Next.js 16 App Router · Node SQLite · Leaflet.
한국어 여행 계획 앱입니다. 샘플은 브라우저 저장소, 계정 여행은 서버 SQLite에 분리 저장합니다.

## 시작하기

Node.js **22.13 이상**(24 LTS 권장)이 필요합니다. 영구 쓰기 가능한 디스크가 있는 Node 서버에서 실행하세요.

```sh
cd Triplan
npm ci
cp .env.example .env.local
npm run dev
```

[http://localhost:3000](http://localhost:3000)을 엽니다. 외부 API 키 없이 교토 샘플로 시작합니다.

운영 실행:

```sh
npm run build
npm start
```

`APP_URL`을 실제 HTTPS 주소로 설정하세요. 쿠키는 HTTPS 요청에서 Secure가 적용됩니다. 리버스 프록시는 SSE 버퍼링을 끄고 업로드 본문 크기를 11MB 이하로 제한하세요. 정적 export, 임시 디스크 서버리스에는 적합하지 않습니다. 여러 사용자가 **같은 서버 주소**에 접속해야 공동 편집됩니다. 다른 컴퓨터에서 localhost 초대 링크를 사용하지 말고 접근 가능한 도메인에서 링크를 생성하세요.

## 먼저 체험할 흐름

1. ‘장소 후보’ → ‘직접 입력 / 링크 추가’로 이름·좌표·비용을 저장합니다. 샘플 검색은 미리 준비한 교토 장소를 검색합니다.
2. 후보의 날짜 선택 또는 일정 하단 후보의 `+`로 날짜에 배치합니다.
3. 일정 카드를 드래그하거나 위·아래 버튼으로 재정렬합니다. 날짜 선택으로 다른 날 이동하거나 후보로 되돌립니다.
4. 지도 번호와 점선이 순서대로 바뀝니다. 장소를 선택하면 지도와 상세 패널이 연결됩니다.
5. ‘예산’에서 장소 비용과 추가 비용의 합계를 확인합니다. 장소는 후보/일정과 무관하게 한 번만 집계합니다.
6. 새로고침하면 샘플 변경 내용이 복원됩니다. 회원가입·로그인 후 ‘내 여행으로 저장’을 누르면 별도 실제 여행을 만듭니다.
7. 다른 계정의 이메일로 초대 링크를 생성하고 직접 전달합니다. 상대는 해당 이메일로 가입·로그인 후 링크를 엽니다. 메일을 자동으로 보내지 않습니다.

## 구현 범위

- 내 여행 목록, 여행 CRUD, 날짜·인원·통화·예산·현지 시간대·항공·숙소 설정, 마지막 계정 여행 재접속 복원.
- 장소 검색(Photon), 직접 입력, 링크 보관, 사진 URL, 메모·분류·희망 상태·비용, 수정·삭제.
- 실제 OSM 지도, 분류별 기호, 날짜 색상, 후보 구분, 방문 순서 번호, 날짜/전체 필터, 선택 연동, 점선 연결.
- 날짜별 드래그 배치·재정렬, 키보드/모바일 이동 버튼, 시간·체류 시간, 일정 충돌 안내. 경로가 조회되면 구간별 실제 거리·시간 및 하루 이동 합계.
- 이메일/비밀번호 가입·로그인·로그아웃. scrypt 해시, HttpOnly SameSite 쿠키, 만료 세션, 이메일별 로그인 시도 제한.
- 소유자·초대받은 멤버만 여행 접근. 소유자만 초대/공유/여행 삭제. 멤버는 여행 내용 공동 편집.
- SSE로 약 2초 간격 변경 반영, 연결 실패 시 15초 재조회. SQLite 조건부 갱신으로 낡은 버전 저장에 **409** 반환. 편집 폼/충돌 중 자동 덮어쓰기 중단. 내 변경안 JSON 저장 후 최신 일정 불러오기.
- 장소에 댓글 작성, 본인 댓글 수정·삭제. 날짜별 일정 항목은 같은 장소 댓글을 사용합니다.
- 항목별 예상 비용, 전체/예상/잔액, 장소 비용 중복 집계 방지. 실제 지출·결제자·균등 분담·최소 통화 단위 정산.
- 예약 상태·링크·마감일 안내. PDF/PNG/JPEG/WebP 실제 파일 첨부·다운로드하여 열기·삭제. 10MB 제한, 파일 시그니처 검사, 여행 권한 확인.
- 준비물·할 일 CRUD/체크. 여행지 현지 날짜의 오늘 일정, 주소 복사, Google Maps 외부 길찾기.
- 비활성화 가능한 읽기 전용 공유 링크. 공유에는 배치한 장소 이름·분류·주소·시간·순서만 포함하고 메모·예약·첨부·예산·정산을 제거합니다.
- 인쇄용 전체 날짜 일정 → 브라우저의 ‘PDF로 저장’. 예약 첨부·메모·비용·정산은 인쇄하지 않습니다.
- 커버 URL·테마 색상·밝음/어두움 저장, 밝은 테마 색상 자동 명도 보정, 반응형 지도/일정 전환, 모달 키보드 포커스와 Escape.

## 지도 및 외부 설정

지도 화면은 `src/components/TravelMap.tsx`에 격리되어 있습니다. 서버 연결은 `src/lib/map-provider.ts`에 분리되어 있습니다.

| 기능 | 기본 동작 | 필요한 설정 / 제한 |
| --- | --- | --- |
| 지도 타일 | OpenStreetMap 공개 표준 타일, 키 없음 | 인터넷 필요. [타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)을 준수해야 합니다. 서비스 규모가 커지면 유료/자체 타일 공급자로 교체하세요. 타일 오류 시 안내와 핀/연결선만 표시합니다. |
| 실제 장소 검색 | 계정 여행에서 Photon 공개 API | `PLACE_SEARCH_URL`로 Photon 호환 엔드포인트 교체 가능. 공개 서버는 SLA·완전한 한국어/POI 검색을 보장하지 않습니다. 검색 실패/결과 없음은 직접 입력으로 전환합니다. [Photon](https://github.com/komoot/photon) |
| 실제 도로 경로 | 미연결. 점선 방문 순서만 표시 | [OpenRouteService](https://openrouteservice.org/dev/#/signup) 계정 키를 `ORS_API_KEY`에 설정합니다. 서버 전용 키입니다. 도보/자동차, 제공 지역·쿼터 내 지원. 경로는 실선으로 표시하고 API가 반환한 구간 거리·시간만 사용합니다. |
| 대중교통 | 외부 Google Maps 길찾기 | 앱 내부 교통 시간 조회 미지원. 지원 지역의 외부 지도에서 확인하세요. |
| 초대 | 이메일 지정 초대 링크 | 메일 서비스 불필요. 사용자가 직접 링크 전달. 지정 이메일 계정만 수락 가능, 7일 만료. |
| 사진·커버 | 원본 URL 보관 | 공개 HTTPS 이미지 URL 권장. 이미지 주소가 만료되거나 연결되지 않으면 표시되지 않습니다. |

`.env.local`을 변경한 뒤 서버를 재시작하세요. 비밀 키를 브라우저 변수(`NEXT_PUBLIC_...`)로 노출하지 마세요.

## 데이터 구조와 API

`src/lib/model.ts`에 TypeScript 자료형·Zod 검증·예산·정산 계산을 정의했습니다.

- `Trip`: 기본 정보, 시간대, 개인화, 항공/숙소, `places`, `costs`, `reservations`, `checks`, `expenses`.
- `Place`: 이름/주소/분류/메모/사진/원본 링크/좌표/희망 상태/비용, `day: 0`은 후보. 배열 순서가 방문 순서입니다.
- `Expense`: 기준 통화의 금액, 결제자 이름, 중복 없는 분담 대상 이름. 이름을 동일하게 입력하세요.
- SQLite: `users`, `sessions`, `trips`(소유자·JSON·단조 증가 version·공유 토큰 해시), `members`, `invites`, `comments`, `files`, `attempts`.
- `DATA_DIR` 기본 `./data`. SQLite 파일과 UUID 파일명 첨부를 함께 보관합니다. 이 디렉터리는 공개 정적 경로 밖이며 Git에서 제외됩니다. 운영 중 SQLite 일관성을 고려해 DB와 첨부를 함께 백업하세요.

주요 API:

```text
POST /api/auth/register | /login | /logout
GET  /api/auth
GET, POST /api/trips
GET, PUT, DELETE /api/trips/:id
GET  /api/trips/:id/events                # SSE; 인증·여행 권한 필요
POST /api/trips/:id/invite               # 이메일 지정, owner
POST /api/accept                         # 토큰 수락
GET, POST, PATCH, DELETE /api/trips/:id/comments
GET, POST /api/trips/:id/files
GET, DELETE /api/trips/:id/files/:fileId
POST, DELETE /api/trips/:id/share         # owner
GET /api/share/:token                    # 공개, 정제된 일정만
GET /api/search?q=...
POST /api/route                          # ORS 키 필요
```

PUT 요청은 `{trip, version}`입니다. 클라이언트가 가진 버전과 DB 버전이 같을 때만 저장됩니다. 자동 병합은 하지 않습니다. 댓글·파일은 별도 자료로 저장하므로 일정 JSON 갱신이 댓글·파일을 덮어쓰지 않습니다. 401/403/404/409/413/429/503 등은 사용자 화면에 오류로 전달되며 성공으로 위장하지 않습니다.

## 검증

```sh
npm run typecheck
npm test
npm run build
npm run test:api
```

API 검증은 3199 포트에 **임시 데이터 디렉터리를 사용하는 별도 서버**를 실행하고 종료 후 삭제합니다. 기존 여행 데이터에 테스트 계정을 넣지 않습니다. 포트 충돌 시 `TEST_PORT=3201 npm run test:api`로 변경하세요.

계산/검증 테스트: 장소 비용 중복 집계 방지, 기간/좌표 검증, 균등 분담 정산. API 통합 테스트: 인증, 여행 저장·조회·삭제, 타인 접근 차단, 지정 이메일 초대, 낡은 버전 충돌, 본인 댓글 권한, 실제 파일 업로드 및 위장 파일 거부, 파일 권한, SSE, 공유 개인정보 제거/철회, 미설정 경로 오류, 외부 출처 변경 요청 차단.

## 남은 제한 사항

- 영구 디스크가 있는 단일 Node 서버용입니다. 여러 서버/리전 운영은 PostgreSQL·객체 스토리지·이벤트 중계로 저장 계층을 교체해야 합니다.
- 이메일 소유권 인증, 비밀번호 찾기, 계정 탈퇴, 멤버 추방은 아직 없습니다. 초대는 지정한 이메일로 가입한 계정 확인 수준입니다. 공개 운영 전 이메일 인증/비밀번호 복구와 운영 정책을 추가하세요.
- 실시간 동기화는 SSE 알림 후 서버 스냅샷 재조회 방식입니다. 문자 단위 동시 편집·자동 병합·수정 이력은 제공하지 않습니다. 충돌 시 변경안을 보존하고 명시적으로 최신본을 불러옵니다.
- 장소 링크 메타데이터 자동 추출, 지도 클릭으로 좌표 입력, 파일 방식 사진/커버 업로드는 미구현입니다. 장소 링크·사진·커버 URL은 직접 입력합니다. 예약 파일은 실제 업로드됩니다.
- 경로 API 키를 제공받지 않아 실제 ORS 성공 응답은 라이브 검증하지 못했습니다. 미연결/조회 실패 처리와 연결 코드는 구현했습니다. 교통체증·대중교통/영업시간/시간대별 도로 상황은 반영하지 않습니다.
- 인터넷 없이 샘플 편집·비용 계산은 가능하지만 지도 타일·실제 검색·사진은 인터넷이 필요합니다. 설치형 PWA·오프라인 지도 캐시는 미지원입니다.
- PDF는 브라우저 인쇄 저장 방식입니다. 자동 파일 다운로드나 서버 PDF 생성은 하지 않습니다.
- 통화는 여행별 하나이며 자동 환산하지 않습니다. 정산은 균등 분담이며 송금 기능은 없습니다. 여행이 자정을 넘는 활동은 수동으로 다음 날짜에 나누어 입력하세요.

## 여행별 테마와 스티커 꾸미기

여행 화면 상단의 ‘테마’와 ‘스티커’ 버튼으로 각각 열 수 있습니다.

- **24종 테마**: 그린 여권, 교토의 가을, 벚꽃 우체국, 바다 소다, 레몬 피크닉, 귤빛 제주, 숲속 오두막, 캠핑 수첩, 알로하 엽서, 눈꽃 산장, 느긋한 온천, 사막의 일몰, 파리의 줄무늬, 유럽 필름, 낭만 열차, 디저트 산책, 러브레터, 체리 온 탑, 북유럽의 아침, 모노 시티, 서울의 네온, 별빛 여행자, 오로라의 밤, 레트로 아케이드.
- 프레임·페이지 배경·카드·강조 색·패턴이 함께 바뀝니다. 모든 테마에서 밝기와 커버 사진/테마 배경을 별도로 선택할 수 있습니다. 지도 날짜 색은 유지합니다.
- **스티커 28종 / 그중 APNG 애니메이션 11종**. ‘스티커’ 팔레트에서 고른 뒤 실제 여행 화면의 원하는 위치를 눌러 붙입니다. 총 40개까지 지원합니다. 드래그·방향키(Shift: 10px), 크기(28~240px), 회전(±180°), 복제·맨 앞으로·떼기·실행 취소를 제공합니다. 모바일에서는 위치를 고를 때 팔레트가 접힙니다.
- 스티커마다 현재 탭 또는 모든 여행 탭에 표시하도록 선택합니다. 커버에 붙이면 기본적으로 모든 탭에 표시합니다. 편집을 마친 일반 화면에서는 스티커가 클릭/터치를 가로채지 않습니다. 텍스트를 가릴 수 있으므로 읽기 좋은 여백에 배치하세요.
- 테마는 미리보기 후 **‘이 여행에 적용’**, 스티커는 **‘저장하고 완료’**로 저장합니다. 테마 변경은 기존 스티커를 교체하지 않습니다. 저장 전 취소·화면 이동에는 확인을 제공합니다. 샘플은 브라우저, 실제 여행은 기존 버전 충돌 방지 API에 저장합니다.
- 자유 배치는 `zone: page`, 가로 비율 `x`, 페이지 상단부터의 세로 픽셀 `y`, 표시 탭 `pageView`로 저장합니다. 세로 위치는 절대 위치이므로 콘텐츠 길이·화면 너비가 바뀌면 스티커를 다시 조절해야 할 수 있습니다. 기존 cover/workspace 스티커는 그대로 읽고 드래그 시 자유 배치로 전환합니다.
- `themeId`, `coverMode`, `decorations`, `stickerMotion`을 여행 JSON에 추가했습니다. 이전 여행에는 기본값을 적용하므로 DB 마이그레이션은 필요하지 않습니다.
- 정적/움직이는 스티커는 원본과 라이선스를 로컬에 보관합니다. 외부 스티커 CDN/API 키 없이 재생됩니다. 기기 `prefers-reduced-motion` 또는 앱의 재생 끄기 설정에서는 정적 PNG로 대체합니다.
- 출처·커밋·파일 해시는 `THIRD_PARTY_NOTICES.md` 및 `public/stickers/manifest.json` 참조. 사용자 업로드 GIF나 외부 GIF 검색은 지원하지 않습니다.
- 공유 일정에도 여행의 테마·스티커는 표시합니다. PDF는 기존의 읽기 쉬운 일정 인쇄 형식을 유지하며 장식은 포함하지 않습니다.

구현 파일: `src/lib/themes.ts`, `src/components/ThemeStudio.tsx`, `src/components/Decorations.tsx`, `src/components/StickerWorkspace.tsx`, `src/app/themes.css`.


## GitHub Pages 배포

공개 체험판: https://piason10.github.io/Triplan/

`main`에 push하면 `.github/workflows/pages.yml`이 단위 테스트 → 정적 빌드 → Pages 배포를 실행합니다. 저장소 Settings → Pages의 Source는 GitHub Actions입니다.

Pages는 정적 호스팅이므로 **브라우저 저장 샘플 여행**을 제공합니다. 장소 저장·날짜 배치·순서 변경·실제 지도·예산·체크리스트·테마·스티커·인쇄/PDF는 체험할 수 있습니다. 로그인, 서버 저장, 공동 편집, 댓글, 파일 첨부, 공유 링크, 실제 경로 API는 Node 서버 버전에서만 실행됩니다. 체험판에는 서버 미연결 안내를 표시하며 API 요청을 보내지 않습니다. 지도 타일과 커버 사진은 인터넷 연결이 필요합니다.

```sh
npm run build:pages
```

`out/`이 생성됩니다. 기본 주소 경로는 `/Triplan`이며, 저장소 이름을 바꾸면 `NEXT_PUBLIC_BASE_PATH=/새이름 npm run build:pages`를 사용하세요. 배포 워크플로는 저장소 이름을 자동으로 사용합니다.

전체 서버 소스는 그대로 유지합니다. `npm run dev`, `npm run build`, `npm start`는 Node 서버용입니다. 정적 빌드는 `.pages-build/` 임시 소스에서 API 라우트를 제외하여 생성하므로 실제 서버 파일을 이동하거나 삭제하지 않습니다. `data/`, `.env.local`, 첨부 파일, 빌드 결과, 의존성 폴더는 Git과 Pages에 올리지 않습니다. 스티커 원본과 MIT 라이선스는 함께 배포합니다.
